# アレンジとライブセッションのテイク仕様

**状態：OSTF Studioの製品仕様・実装予定。** この文書は画面操作と再生結果を定める。OSTF 5.1の策定、ファイル内の表現、OSTFPへの保存方式は別途扱う。

## 1曲に1つの採用結果

テイクは、同じトラックの別演奏を曲の時間軸に揃えて保持する。トラックの音源・FX・ミキサー設定、曲の構成・コード進行・スケール・テンポ・拍子は共通とする。既存曲を開いたときは、現在の演奏を各区間の **T1（採用）** として扱う。曲を開くだけで元ファイルを書き換える処理は行わない。

普段の採用単位は **1トラック × 1構成**。たとえばギターでサビにT2を追加すると、その区間に入力できる空のT2ができ、Aメロや他の楽器には影響しない。追加すると編集先がT2になる。再生はT1のまま続く。テイク番号はトラック内で識別し、同じT2レーンには後から別の構成の演奏も置ける。移動や削除のあとも既存の選択が同じ演奏を指すようにする。

| 操作 | 耳に聞こえる演奏 | 曲に採用される演奏 |
|---|---|---|
| T2を追加し、選択して入力・録音 | T1の伴奏と、モニターが有効なら演奏者の入力 | T1 |
| T2の▶で試聴を予約 | その構成に次に入る頭から、そのトラックだけT2。ループの頭も対象 | T1 |
| T2を「採用」 | 試聴中ならそのまま続く。直接採用した場合も、すでに鳴っている区間は最後まで演奏する | 両ビューで対象区間がT2 |
| 「採用中に戻す」 | 未発効の試聴は取り消す。発効済みなら次にその構成に入る頭から採用テイクに戻る | 直前の採用結果 |

アレンジでの通常再生と曲の書き出しは採用結果を使う。ライブセッションでだけ、試聴中のセルがその採用結果に一時的に優先する。ビューの切替で進行中の演奏が変わることはなく、停止すると試聴と予約が解除される。次回は両ビューとも採用結果から始まる。

## アレンジで細かく選ぶ

トラックを展開すると、上段に採用中の演奏、直下に同じ小節目盛りでT1・T2のレーンが並ぶ。「テイク追加」は選択した構成に作成し、選択範囲がある場合はその範囲に作成する。各レーンから「この区間で採用」を実行できる。上段とライブのセルは同じ採用結果を表示し、どちらで変更しても1回のUndoで両方が戻る。

8小節のサビを5小節目の頭で切ると、そのトラックの全テイクで同じ拍に境界ができる。前半はT1、後半はT2を採用でき、ライブのセルには左から **T1｜T2** と表示する。ハサミを入れただけなら、境界をまたぐMIDIの長音は一度だけ発音し、オーディオは元の再生位置で連続する。実際に別テイクへ切り替える境界では、旧テイクの音を解放し、新テイクのその位置で鳴る音へ接続する。構成全体を改めて採用すれば全区間がそのテイクに切り替わり、Undoで以前の前半・後半の選択を復元できる。

## ライブで組み合わせる

構成を行、トラックを列とするグリッドを維持する。セルには採用テイクと試聴・予約状態を文字で示す。セル本体を押すと下段に共通のエディターが開き、空セルでも入力できる。テイク一覧の追加・試聴・採用を同じセルから操作する。

- **セルの▶／試聴解除**はその楽器だけを対象とする。他のトラックの演奏位置と曲のコード進行は保たれる。構成の途中で次のテイクを予約した場合、発効前なら別のテイクに予約し直せる。
- **行の▶**はその構成へ全トラックを揃えて進める。停止中はその構成の頭から開始し、再生中は次の小節頭で切り替える。画面には切替先の構成名と「予約中」を示す。その頭で各トラックの採用テイクと、明示的に予約した試聴テイクが揃って発音する。セルの編集選択だけでは再生位置は動かない。
- **「この構成の組み合わせを採用」**は、その行で実際に聴いている組み合わせを1回で曲に反映する。まだ発効していない予約は含めない。表示フィルターで隠したトラックも含め、試聴による変更がないセルの区間別採用はそのまま保つ。Undoも1回とする。
- **ループ回数**はその構成を演奏する総回数とし、初期値1、0はスキップ、2は計2回。再生中は現在の周回と残り回数を表示する。演奏中の構成を0にしたら今の周回末で次へ進む。未到達の構成を0にしたらその構成への起動予約も取り消す。スキップ中の行はセルを編集でき、回数を1以上に戻すと起動できる。

## 再生中の入力と構成変更

画面への編集反映と、いま鳴っている演奏への反映には別のタイミングを使う。入力はサンプルクロックに沿って、録音開始時に指定したトラックとテイクに記録する。複数の構成を通して弾いた場合は、実際に演奏した構成とその中の位置に対応付ける。画面の選択変更や並べ替えで録音先がずれないようにする。

| 再生中の操作 | 次に聞こえる結果 |
|---|---|
| ピアノロールに入力、または録音を確定 | 編集結果は両ビューにすぐ表示。再生済みの音は再発音せず、対象区間の次回再生で編集済みテイクを使う。入力モニターは操作中も継続する。 |
| 現在と次の構成の間に新しい構成を挿入 | 境界までに準備ができていれば、現在の周回・指定回数を終えた後に新しい構成へ進む。再生位置より前への挿入で先頭へ戻ることはない。 |
| 将来の構成を削除・並べ替え | 次の行き先を最新の順序と回数で決める。削除されたセルの試聴予約は取り消す。 |
| 鳴っている構成を削除・移動 | その周回だけを元の末尾まで演奏する。削除なら元の順序で次に残った構成へ、移動なら新しい位置の次の有効な構成へ進む。削除操作では巻き戻しや意図しない再ループを発生させない。 |
| トラックを追加・複製・移動・削除 | 既存の入力・演奏・採用結果をトラックの識別子に追従させる。複製は独立に編集できる。削除時は対象の音だけを解放する。録音先を削除する場合はその時点までの収録を確定し、削除のUndoで演奏素材も復元する。 |

構成の複製は、その範囲の全テイク、区間境界、採用結果を引き継ぐ。複製先の編集は元の構成から独立させる。演奏可能な構成がすべて削除されたり0回になったときは、ライブの時計と入力モニターを動かしたまま伴奏を待機する。再び演奏可能な行を指定すれば、次の小節頭から合流できる。通常どおり曲の最終周回を完走したときは曲末として扱う。

再生計画と必要な音源はオーディオコールバックの外で準備し、準備済みの変更を音楽的な境界でまとめて反映する。境界に間に合わなければ現在の有効な計画で演奏を続け、画面には次の反映時点を示す。編集を適用するための停止・再スタートや、オーディオデバイスの開き直しは行わない。

## 実装時の受け入れ確認

1. 既存曲でT2を追加して録音し、未採用のまま通常再生・書き出しを行う。元のT1の演奏と一致することを確認する。
2. サビをループさせ、ギターT2・ベースT3・歌T1を聴いて一括採用する。アレンジにも同じ組み合わせが現れ、1回のUndoで各セルの元の採用に戻ることを確認する。
3. MIDIの長音と持続するオーディオをまたいで分割し、同じテイクのままなら分割前と同じ音が出ること、区間別採用が両ビューで一致することを確認する。
4. 入力を続けながら構成の追加・複製・移動・削除と0回スキップを行う。音声クロック、録音の連続性、実際に訪れた構成の順序、取り消された試聴予約を確認する。
5. プロジェクトを再度開いたときに全テイクと区間別採用が復元され、一時試聴が通常再生に混入しないことを確認する。保存形式の互換試験は正式な仕様確定後に追加する。
