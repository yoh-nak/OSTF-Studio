# SUPER KNOBBER REVERB

[日本語](super-knobber-reverb.md) · [All plug-ins](en.md)

**Signal path.** Use matching mono or stereo input and output. On a track insert, mix the reverb with **Dry / Wet**. On a return, set it to 100% wet and adjust the track send.

![SUPER KNOBBER REVERB controls](../images/plugins/super-knobber-reverb.png)

| Control or display | How to use it |
| --- | --- |
| Space, source profile and style | Choose a starting point. Short hits make differences in the tail easier to hear. |
| Pre Delay and Decay | Adjust the gap after the dry sound and how long the tail rings. |
| Early Level and Tail Level | Balance the first reflections against the diffuse tail. |
| Spectrum and EQ comparisons | Compare the input filtering or post EQ before and after processing. |
| WET peak, RMS and correlation | Peak follows instantaneous level, RMS follows average level, and correlation shows left/right similarity. The five RT60 values are decay targets. |

When exporting a song, set **Effect tail after song end** long enough to hear the final decay. [Complete control ranges and defaults](../../src/plugins/effects/knobber/Controls.h)
