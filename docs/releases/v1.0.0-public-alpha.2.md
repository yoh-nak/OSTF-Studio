# OSTF Studio Public Alpha 2

This pre-release adds a workstation instrument for VST3 hosts. Install **OSTF Studio (VST3)** on an instrument track, open a song inside it and enable **Follow DAW transport**. The workstation returns a stereo mix. Match the host and song tempo and meter maps if their bar numbers need to align.

## Changes since Public Alpha 1

- **Composition.** Scale Editor now edits the hosting Studio project directly. Select a chord and a harmony or track destination, audition a section or the whole song, and see the sounding scale. From another DAW, open Scale Editor inside Studio VST3. The previous release retains its own file-based workflow.
- **Arrangement.** Edit chord, key, meter, section and scale regions from the lower editor. Drag shared edges with musical snapping, insert bars, move a clip selection to the cursor, and set a drum loop on the ruler. The last key stays visible at song end. Click its Camelot number for the wheel.
- **Editing and export.** Edit notes in the piano roll beside their part score. Adjust warp timing and monophonic pitch in the audio editor. Export a stereo mix with an effect tail or bounce selected tracks and clips to a muted audio track. Synthesizer V export offers lead, chorus or separate vocal tracks in one SVP file.
- **Plug-ins.** The bundle grows from 38 to 41 VST3s with OSTF Studio, SUPER KNOBBER LEAD and SUPER KNOBBER REVERB. LEAD offers 188 source patches and optional 2× oversampling. REVERB adds signal meters, spectrum, wet history and stereo analysis. Preset selection and wet-level metering were corrected. Individual inserts can be bypassed and reordered. Supported stock devices share MIDI CC learn with channel-specific recall.
- **Installation.** The full install starts with every device selected. You can choose only the workstation VST3 and the demo devices for another DAW. Selecting the project-dependent Scale Editor also selects the Studio application.
- **Score compatibility.** Studio continues to open supported OSTF 5.0, 5.1 and 5.2 material. Keep production routing, plug-in state and bundled audio in OSTFP. MIDI takes and comp selections use the source score version.

## Packages and verification

Choose Windows x64 Setup or the portable ZIP. For a Mac, choose the DMG for Apple silicon (arm64) or Intel (x86_64). Both contain the standalone application and the selectable VST3 installer. These are separate native builds. The corresponding-source archive includes the pinned build inputs. See the [illustrated manual](https://github.com/yoh-nak/OSTF-Studio/blob/v1.0.0-public-alpha.2/docs/manual/en.md) and [41-device guide](https://github.com/yoh-nak/OSTF-Studio/blob/v1.0.0-public-alpha.2/docs/plugins/en.md).

Windows binaries are unsigned. The Mac packages have no Developer ID signature or Apple notarization. CI exercises the build, test suite and installer on each platform. Physical audio/MIDI hardware, commercial DAW compatibility and a live authenticated AI session require separate verification. A remote AI account is optional.

## Known limits

- Follow DAW transport uses time position and the OSTF tempo map. Align the initial downbeat, meter and tempo maps to match bars.
- Independent pitch editing targets monophonic intervals. Split a repeating MIDI clip before inserting bars inside the loop. Bar insertion is restricted for authored notation and musical time maps.
- External MIDI hardware must be recorded to audio before offline export. On macOS, MP3 mix export needs an available LAME encoder. Save a separate OSTFP when trying production edits in this alpha.
