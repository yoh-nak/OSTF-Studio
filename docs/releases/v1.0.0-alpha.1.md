OSTF Studio初の公開アルファ版です。Windows x64用のインストーラーとPortable ZIP、AppleシリコンMac用のDMGを配布します。

- **デモを試す** — 起動後に再生するか、File → Demo songs から曲を選びます。Global Timelineでコードやセクションを確認し、トラックを選ぶとピアノロールにノートが表示されます。
- **音源とミキサー** — OSTF GM Sound Moduleには16パートのGM音源とFluidR3 GMを同梱しています。バス、リターン、マスターにエフェクトを挿入できます。外部DAW向けにはOSTF ArrangerとGM音源のVST3を同梱しています。
- **ファイル** — 対応範囲のOSTFスコアとOSTFPプロジェクトを開いて保存できます。混合拍子のプレビュー、歌声合成、オーディオ録音は今後の開発項目です。

WindowsのSetup.exeはユーザーごとにインストールします。MacではDMG内の **Install OSTF Studio and VST3.pkg** でアプリと音源の両方をインストールできます。WindowsのAuthenticode署名、MacのDeveloper ID署名・公証は未設定です。実機のオーディオ機材や外部DAWとの組み合わせは検証途上です。
