## Changes since alpha 2

- Start with an empty project or open one of six mixed demos. Hear the nine bundled effects on individual tracks, buses, returns and the master. Track headers and the mixer display stereo levels.
- Use **Home**, **Rewind** and **Forward** to move through a song. The transport shows the current section, chord, tempo, key and timecode. **Follow** keeps the playhead visible in the arrangement and piano roll. Each editor has its own zoom.
- Open the lead sheet or score from the view toolbar. Follow playback, choose lyric and scale overlays on the lead sheet, print to PDF, or export a part as MusicXML.
- Open standalone OSTF 3.5.0, 4.0.0, 4.1.0, 4.2.0, 4.3.0 and 5.0.0 scores. Saving an older score or packaging it writes OSTF 5.0.0. The preview supports one meter, eight source tracks and up to 256 bars.
- Import a MIDI performance or WAV into a new project. The experimental transcription mode produces a draft melody from a short monophonic recording.
- Windows Setup can install Studio first and update shared VST3 plug-ins later. If a DAW has an identical plug-in binary loaded, Setup can repair the missing bundle files without closing the DAW.

## 日本語

「ファイル → デモソング」でロックやトランスを含む6曲を試せます。ミキサーのメーターとエフェクト、現在の構成名を示すトランスポート、再生に追従するリードシートと楽譜を追加しました。旧版のOSTFは3.5.0から読み込めます。Windowsで他のDAWを使用中の場合は、Studio本体を先にインストールし、共有VST3の更新を後回しにできます。

Windows packages are unsigned. The macOS package and disk image are distributed without Developer ID signing or notarization.
