## Changes since alpha 1

- Export a song from **File → Save as MIDI (SMF)**. Format 0 combines the parts into one MIDI track. Format 1 writes a conductor track and named part tracks. Both preserve the score's timing and MIDI channels.
- Choose **Settings → Language** to use English, Japanese or the OS display language. Restart Studio to apply a change. Other display languages currently use English.
- Use the icons below the menu bar to show or hide the piano roll, mixer, plug-in browser and output tracks, or to choose individual Global Timeline lanes.
