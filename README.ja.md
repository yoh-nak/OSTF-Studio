# OSTF Studio

[English](README.md) · **日本語**

次のリリースでは、ミキサーの音量を金属調のフェーダーで、パンとセンド量を独立したノブで調節できます。数値を直接入力することもできます。「設定 → 配色テーマ」にはフォレスト・コンソール、ミッドナイト・インディゴ、カッパー・コンソールが加わり、全7色から選べます。同梱のGM音源と9種類のエフェクトにも実機風の操作子を採用しています。

「モード」からAI Arrangement Studio、AI Lyric Studio、AI Vocal Studioを選べます。プロンプトガイドは選んだモードの例文を15秒ごとに1件ずつ表示します。「‹」「›」で前後に移動すると、そこから15秒間その例文を表示します。上部ツールバーでChatGPTの接続やモデル選択ができます。解析したパートは同種のトラックへ追加でき、ほかの位置に置くと新規トラックになります。必要に応じて曲が延長されます。メロディートラック本体の初期高さは100 pxです。

「外部連携」からSplice、Melodyne、Ableton Linkを開けます。ピアノロールと波形エディターのクリップレーンには、小節位置に合わせてクリップ名が表示されます。オーディオクリップを選んでMelodyneを開くと、そのクリップのソース範囲が渡されます。選択が空の場合はMelodyne単体版が開きます。

Liveとの同期は、両方でAbleton Linkを有効にします。再生・停止も同期するにはLiveの「Start Stop Sync」を有効にしてください。Studioの「外部連携 → Link テンポ」で接続台数の確認とテンポ変更ができます。オーディオ録音中はテイク開始時のテンポで収録します。

MIDIトラックの「IN」で入力ポートとチャンネルを選びます。鍵盤やパッドを押すと、その入力を受けるトラックのランプが点灯します。音源の出力レベルはメーターで確認できます。録音先の「R」を押して待機させ、トランスポートで録音を開始します。エディター内の録音ボタンは、そのトラックを待機にして録音を開始します。オーディオトラックは波形を表示し、適合率レーンの高さを取りません。

「設定 → Mackie Control」で、機材をMCUモードにして入力ポートを選びます。フェーダーで音量、エンコーダーでパン、各列のボタンで録音待機・ソロ・ミュート・トラック選択を操作します。バンク・チャンネル移動と再生・停止・録音にも対応します。フェーダー位置やランプを機材に返す場合は出力ポートも選んでください。トラック名はダブルクリックで直接編集し、Enterで確定、Escで取り消せます。

「外部連携 → Splice Sounds を開く」で、スキャン済みの公式VST3が独立したウィンドウで開きます。閉じたあと同じメニューを選ぶと、同じインスタンスを再表示します。ダウンロード済みのWAVファイルはオーディオトラックにドロップできます。

MIDIトラックの「IN」で入力を選び、「R」を押すと停止中も音源を演奏でき、トラックとミキサーに音量が表示されます。外部音源はトラックの音源ボタンの「MIDI OUT」で出力ポートを選んでください。鍵盤入力と曲のMIDIが外部へ送られます。外部音源の音量をStudioで確認するには、戻りの音声をオーディオ入力に接続します。

OSTF Studio は、楽曲の構造と演奏情報を OSTF 5.0 で扱う Windows・macOS 用の DAW です。現在は 1.0.0 のアルファ版を公開しています。同梱のデモ曲で、グローバルタイムライン、ピアノロール、VST3 音源とミキサーを試せます。

## 音源と素材ブラウザー

「ファイル → デモ曲 → First Light Vector」では、アルペジオにFM、ベースにアナログ、ドラムにドラムマシン、パッドにウェーブテーブル音源を使用します。各音源のプリセットはプログラムチェンジの値0〜3で選べます。49小節目で4パートの音色が切り替わります。

右ペインの「オーディオ素材」でフォルダを開き、WAV・AIFF・FLAC・MP3をオーディオトラックにドラッグできます。ピアノロールでは対象レーンを選び、「数値を入力」からプログラム番号やCC値などを指定できます。

## 開発版の波形エディターと理論ガイド

ピアノロールと波形エディターでは、定規をクリックして録音の開始位置を決めます。Shift＋ドラッグ、または「ループ範囲」をオンにしてドラッグすると、拍や小節の途中にも範囲を設定できます。「録音を終了」でクリップを確定し、エディターを閉じます。メトロノームボタンは左側でオン・オフ、右側でカウントインなし、または1〜8小節を選べます。早送りの隣にある「末尾へ」で曲の終端に移動します。

ステップ画面ではパッド1が下段にあり、「行を上へ」「行を下へ」でキットを並べ替えられます。パッドの出力ノートを割り当て、「MIDIラーン」を押して実機のパッドを叩くと入力ノートが登録されます。停止中はパッドとキットの行が同時に点灯します。機器のMIDI入力はオーディオ／MIDI設定で有効にしてください。曲を開いたときの横表示は最大10小節で、アレンジトラックの初期高さは100 px、グローバルと出力系のトラックは28 pxです。

MIDIのループ録音は各周のノートを重ねます。オーディオは最初の有効入力1本（モノ）または2本（ステレオ）を収録し、周回時は今回録音した区間を最新の演奏で更新します。既存クリップの置き換えには確認が出ます。音声は1トラック1クリップ、WAVは16 MiBまでです。

オーディオトラックを選ぶと画面下段に波形が開きます。「ループ」をオンにしてタイムラインのクリップ右端をドラッグすると素材を繰り返せます。「ワープ（変速）」では1周期の長さを四分音符単位で指定できます。波形をダブルクリックしてマーカーを追加・削除し、左右にドラッグして発音位置を調整します。速度に応じて音程も変わります。「Splice Sounds」で公式VST3を開くと、Studio内でライブラリの検索・試聴ができます。使用するWAVをオーディオトラックにドロップします。未導入の場合は、公式の入手先とスキャンを選べます。[Spliceの機能と対象プラン](https://support.splice.com/en/articles/12997860-splice-sounds-plugin-faq)

「Melodyne」を押すと、選択したクリップの音声を編集用WAVとしてMelodyne単体版で開きます。Melodyneで「オーディオを置き換え」で保存し、Studioの「編集したWAVを反映」で取り込みます。理論ガイドでは度数行の括線が進行の範囲を示し、その下に和声機能が並びます。

## 取り込みと解析（開発版）

「ファイル → 取り込み・採譜」でオーディオ、MIDI、PDF楽譜を選ぶと、解析結果がパート別に表示されます。必要なパートだけを本画面へドラッグするか、一式を同じ本画面で未保存の新規曲として開けます。256小節を越える録音にも対応します。オーディオ解析の仮グリッドは120 BPM・4/4、取り込みの上限は6万ノート・15パートです。

PDF楽譜の「ロジック解析」には、このコンピューターにインストールしたAudiverisを使います。取り込み画面の「Audiverisの入手方法」から公式の案内を開けます。セットアップ後は同じ画面の「このPDFを再試行」を押してください。Windowsでは標準インストール先、ユーザーの `%LOCALAPPDATA%\Programs\Audiveris`、PATH上の実行ファイルを検出します。認識結果は元譜のテンポ、コード、音符と照合してください。原本のMusicXMLがある場合は、そのファイルを直接取り込めます。


「ロジック解析」はローカルで動作します。PDFのロジック解析にはAudiverisを使用します。「ファイル → インポートと採譜」でMusicXML（.musicxml / .xml / .mxl）を選び、「新しい未保存の曲としてここに開く」からOSTFに保存できます。「ファイル」メニューから全パートのMusicXMLと、コード・歌詞をまとめたChordProを書き出せます。[8小節の検証用PDF](examples/score-interchange/lantern-walk.pdf)と[比較用MusicXML](examples/score-interchange/lantern-walk.musicxml)をリポジトリの `examples/score-interchange` に用意しました。「AI解析」を使うには、公式Codex CLIを用意し、グローバルトラック左の「ChatGPT に接続…」または「設定 → AI接続…」からブラウザーでChatGPTにログインします。初回はStudio用に認証します。ブラウザーが自動で開かない場合は「認証ページを開く」を押してください。ファイルを選ぶ前に解析方式を指定してください。AIに送るデータは、オーディオでは音高・時刻・音色の測定値、MIDIでは音域や拍ごとの音の分布、PDFでは譜面のページ画像です。結果は取り込み後に編集できます。[ChatGPTの認証](https://developers.openai.com/codex/auth) · [Audiverisの使い方](https://audiveris.github.io/audiveris/_pages/guides/advanced/cli/)

## alpha 3 で旧版の曲を開く

開発版のピアノロールでは、空白のダブルクリックでノートを追加し、中央をドラッグして移動、左右の端で長さを変更できます。Shift＋クリックや範囲選択で和音をまとめて編集できます。Alt／Option＋ドラッグで複製、Ctrl／Command＋上下ドラッグでベロシティを調整できます。入力の刻み幅はピアノロール右下のグリッドで選べます。ほかの操作は「ヘルプ → ショートカット一覧」にあります。

ピアノロールの小節ルーラーをクリックすると再生カーソルが移動し、左右にドラッグすると表示範囲が移動します。オーディオトラックには実際のWAVの波形を表示します。**Relay Circuit** の45小節ではタムとダブコード、**First Light Vector** の49小節ではゲート音とベルが重なります。各オーディオトラックのソロで聴き比べられます。

開発版では、ツールバーからメロディー、コーラス、音階付き、ドラム、オーディオ、バス、リターンを追加できます。アレンジ画面またはミキサーでトラック名を右クリックすると複製・削除ができます。虫眼鏡のボタンで画面全体を75〜150%に調整でき、倍率は次回起動時にも保持されます。アイコンにカーソルを置くと操作内容が表示されます。

**ファイル → 開く**で、3.5.0、4.0.0、4.1.0、4.2.0、4.3.0、5.0.0 の単体の `.ostf` を直接開けます。元の曲は開いた時点で保持されます。**OSTF で保存**と**OSTFP で保存**はスコアを5.0.0で書き出し、旧版を開いたあとの初回保存では別名を提案します。開発版では最大15パートを読み込めます。

## alpha 3 のトランスポートと曲情報

**ファイル → 曲の設定**、またはツールバーのメトロノームのアイコンから曲の設定を開けます。**曲の基本設定**でキー、スケール、開始テンポ、拍子を設定できます。区間にキーやスケールを指定してある場合、その区間では区間の指定が優先されます。**曲全体を移調・テンポ変更**は音階付きノートと和声を移調し、すべてのテンポに倍率をかけます。「曲の編集を取り消す」で元に戻せます。**試聴用の移調・テンポ**は、曲を保存する前に別のキーや速度を試すための設定です。曲を開くと試聴設定が解除されます。録音済みのオーディオ素材は元の音程と速度で再生します。

ツールバーにある3点を結んだアイコンで理論ガイドを切り替えられます。トラック名の左には、音階付き楽器を示す鍵盤、ドラム、オーディオ波形などのアイコンがあります。ピアノロールでは小節ルーラーの下にコード名が並びます。和声による色分けを選んでノートをクリックまたはドラッグすると、選択した音のコード適合率とスケール適合率が表示されます。コードをまたぐ音では、それぞれのコード上で鳴った長さに応じて割合が変わります。

トランスポートには、現在位置の構成名・テンポ・拍子・キー・スケール・コードと、小節・拍・ティック・30 fpsの経過タイムコードが表示されます。「先頭へ」で曲頭に戻り、「早戻し」「早送り」はクリックで1小節、長押しで連続移動します。停止後はその位置から再生やMIDI録音を開始できます。曲末で再生を押すと先頭から始まります。録音中の位置移動は停止後に行えます。

「追従」は初期状態でオンです。金色の再生線が右端に近づくと、アレンジ画面とピアノロールが同じ拡大率で一緒に横スクロールします。別の箇所を見ながら再生したいときはオフにし、再生位置に戻りたいときはオンにしてください。曲名とファイル名はウィンドウのタイトルバーで確認できます。

**ファイル → 曲情報を編集**で曲名、副題、説明、クレジットを設定できます。同じ人が作詞と作曲を担当した曲では、同じ名義で `lyricist` と `composer` の2行を追加します。**適用**のあと、OSTFまたはOSTFPで保存してください。

## alpha 3 のリードシート・楽譜・採譜

ビューバー左端の3つのアイコンで、メイン画面を **アレンジ・リードシート・楽譜** に切り替えます。「表示」メニューからも同じ画面を開けます。再生中は金色の線が演奏位置を示し、「再生に追従」がオンなら次の小節に表示が進みます。追従をオフにすると、再生を続けたまま別の箇所を読めます。

リードシートではコード・スケール・歌詞を個別に表示でき、1行の小節数を1・2・4・8・16から選べます。歌詞がある曲では歌詞パートと本文・発音の表示を選べます。発音の指定がない箇所には本文を表示します。楽譜ではトラックごとに大譜表、ト音記号、ハ音記号（アルト）、ヘ音記号、ギターTAB、ベースTAB、ドラム譜表を選べます。**PDF保存・印刷** で選択した内容をA4に整えて出力し、PDFビューアーから印刷できます。楽譜は **MusicXML** でも書き出せます。

**ファイル → 取り込み・採譜** でパートを確認できます。オーディオからは音符、ドラムの打点、長三和音・短三和音の候補を推定します。別画面に並んだパートを本画面の対応トラックへ、コード進行をコードレーンへドラッグできます。ドラッグ中に現れる「ここにドロップして新規トラックを追加」を使うと、取り込み先も一緒に作れます。「本画面で未保存の新規曲として開く」を選ぶと、現在のウィンドウで解析した一式を編集できます。保存先は後から選べます。

ロジック解析はPC内で行います。モノラルまたはステレオのWAV、AIFF、FLACなどに対応します。音声のグリッドは暫定の120 BPM・4/4です。メロディー、伴奏、ベース、打楽器は演奏上の役割です。単独で鳴る音の倍音構成が内蔵GM音源の楽器群と継続して一致した場合、パート名に「ギター（候補）」などの音色候補も表示します。MIDIは元のトラックとチャンネル別に表示します。PDFはロジック解析とAI解析を選べます。

ドラムトラックはGMベースの16パッドで開始します。左側でパッドのノート変更・追加・削除ができます。スロットはキット順、ピアノロールは割り当て音を高い順に表示します。スロットでは4×4・8×8のパッドを切り替えられます。停止中に打音を書き込むには、ステップのマスをクリックします。MIDI録音では画面のパッドや有効にした外部MIDI入力の演奏を記録できます。

トランスポートの横または下にある「曲の基本設定」は横一列で表示します。「詳細」を開くと、画面幅にかかわらず全項目とクレジットを編集できます。ウィンドウのタイトルバーには曲名、ファイル名、未保存の状態が表示されます。BPMレーンを選ぶと下段にテンポエディターが開き、クリックでBPMを設定、ドラッグで加速・減速を描けます。アレンジトラック本体の初期高さは100 pxです。「コード適合」「スケール適合」は各16 pxで、本体の縦ズームや折りたたみから独立しています。度数の色とノート下線の意味は全テーマで共通です。グローバルレーンの値はダブルクリック、カット・コピー・ペーストは右クリックで操作します。トラック名はダブルクリックで変更できます。ピアノロールの音程数は上端のメニューで変更でき、下部のパラメーターレーンとの境界をドラッグして高さを調整できます。

## インストール

Windows は Setup.exe を実行するか、Portable ZIP を展開してください。Apple silicon Mac は DMG を開き、中の **Install OSTF Studio and VST3.pkg** でアプリと VST3 をインストールします。macOS の Developer ID 署名・公証は未設定です。公開版のインストーラーと対応ソースは [GitHub Releases](https://github.com/yoh-nak/OSTF-Studio/releases) の各リリースの **Assets** にあります。

開発ビルドは **Actions → 各ビルドの実行結果 → Artifacts** に7日間保存されます。公開版の履歴・配布ファイルは Releases から取得できます。

## MIDI書き出し・言語設定・表示切り替え

- **ファイル → MIDI（SMF）で保存** で曲全体を `.mid` に書き出します。フォーマット0は MIDI チャンネルを保ったまま全パートを1トラックにまとめます。フォーマット1はテンポ・拍子のトラックと各パートの名前付きトラックに分けます。録音したノート、GM マッピングのあるドラム、プログラムチェンジ、CC、ピッチベンド、アフタータッチも対象です。WAV・プラグインの設定・歌唱曲線は OSTF プロジェクトに保存してください。コードから表示用に展開したボイシングを重複して書き出すことはありません。
- **設定 → 言語** で「OS の表示言語を使用」「English」「日本語」から選べます。変更は次回の起動時に反映します。初期設定では日本語環境なら日本語、それ以外の環境では英語で開きます。
- メニューバーの下のアイコンで、ピアノロール、ミキサー、プラグインブラウザー、出力トラックの表示を切り替えます。レーンのアイコンではグローバルタイムラインの表示項目を選べます。アイコンの上にポインターを置くと機能名が表示されます。

## 曲を開いて演奏する

**File → Demo songs** でデモを選ぶか、**Open OSTF / OSTFP** で手元の曲を開きます。セクション、コード、調、拍子、テンポとトラックのクリップが共通の小節位置に並びます。コードのボイシングはグローバルの1行に表示されます。楽器で実際に弾く伴奏パートはアレンジ側に残ります。[デモ曲と確認できる項目](examples/demo-songs/README.md)

トラックを選ぶとピアノロールに音高と長さが表示されます。曲に記録されたベロシティ、CC、アフタータッチ、ボーカルのピッチと表現曲線も確認できます。アレンジとピアノロールはそれぞれ横方向に拡大・縮小、スクロールできます。**Drag MIDI to another DAW** は選択した音階付きトラックを別の DAW へドラッグする機能です。

**Settings → Audio / MIDI Devices** で機器を選びます。Windows は WASAPI と ASIO、Apple silicon Mac は Core Audio に対応します。ASIO の利用には対応機器のドライバーが必要です。MIDIトラックで **IN** から入力を選び、**R** で待機してトランスポートの録音ボタンを押します。停止時に録音したノートがクリップになります。オーディオトラックは波形エディターでモノラルまたはステレオを選べます。

## 音源・エフェクト・ミキサー

alpha 3 は、120 BPM・4/4・32小節の空の新規プロジェクトで起動します。「トラック」から最初のパートを追加できます。「ファイル → デモソング」にはロックの Copper Mile、トランスの First Light Vector を含む6曲があります。

開発ビルドには音を加工する9種類のエフェクトと、解析用VST3の **OSTF Wave Analyzer** を同梱します。解析器をマスターまたは個別トラックのFXに挿すと、左右の波形とスペクトル、ピークとRMS、位相相関、3種類のLUFS、最大トゥルーピークを確認できます。スペクトルにカーソルを置くと周波数とレベルを表示します。Freezeで表示を固定し、Reset metersで積算をやり直せます。**File → Demo songs → Paper Lantern Replies** を開くと、リードボーカルの **EQ → Compressor**、ドラムとベースの Bus A、伴奏の Bus B、Return 1 のリバーブを確認できます。トラックのセンド量、パン、フェーダー、エフェクトの順番を `.ostf` と `.ostfp` の両方で復元します。[デモ曲ごとの試聴手順](examples/demo-songs/README.md)

プラグインブラウザーには VST3 がメーカー別に表示されます。初回のスキャン結果はこの PC に保存されます。楽器とエフェクトを絞り込み、トラックへドラッグして割り当てられます。見つからない場合は **Scan one…** から個別に VST3 を選択できます。

**OSTF GM Sound Module** はチャンネルごとに音色、音量、パン、エクスプレッションなどを設定できる16パートの音源です。チャンネル10は打楽器です。配布版は FluidR3 GM を同梱しており、手元の SF2 も読み込めます。複数トラックで1つの音源を共有するには **Instrument → Instrument destination** で同じ音源トラックを指定し、各パートの MIDI チャンネルを選びます。共有音源のステレオ出力は音源を置いたトラックで調整します。[FluidR3 の配布条件](licenses/NOTICE.md)

**OSTF Arranger** は通常のインストゥルメントスロットに置きます。プラグイン内の **Choose instrument** で発音する VST3 音源を選びます。生成したパターンを Studio のトラックには OSTF ノートとして、外部 DAW には MIDI としてドラッグできます。外部 DAW ごとの動作検証は継続中です。

次期設計では、Composerと各パートのアレンジャーでコードの解析・進行生成を共有します。OSTFの既存コードはフレーズと一緒に取り込み、未設定の区間は演奏から候補を出せます。採用した進行は各パートで利用できます。プラグイン内でフレーズの最後だけ別案を作り、同じループで聴き比べて採用できます。[アレンジャーの設計と試験項目](docs/ARRANGER_PHRASE_EXCHANGE.ja.md)

**表示 → 理論ガイド → 理論ガイドを表示**で「度数」「和声機能」「コード進行」の3段を表示します。T はトニック、S はサブドミナント、D はドミナント、プライム記号は代理機能です。C メジャーの Dm7 → D♭7 → C は ii–subV–I と表示します。全有音程トラックとコード・ボイシングの下に、発音時間で重み付けした「コード適合」「スケール適合」が並びます。50% 未満は赤、50～74% は橙、75～89% は黄土色、90% 以上は緑です。休符や参照のない区間は「—」、ドラムとオーディオは「対象外」です。

ピアノロール左上で **白鍵・黒鍵／コードモード／スケールモード** を選べます。コードモードはコード名とルートからの度数、スケールモードは適用されるスケール名と主音からの度数を示します。ノート本体の色は度数、下端の色は和声上の役割です。Cmaj7 と C Ionian の区間では、G は完全5度、D は使用可能な9度、F は E と重ねて伸ばす場合のアボイド候補になります。コードに明示されたテンションを優先します。持続音は1ノートのまま、和声の境界で色が切り替わります。色見本は編集パネル内にあります。

選択したノートに対して、左パネルでグリッドと強さを選び **選択音をクォンタイズ** を押すと、音の長さを保って開始位置を寄せます。**ベロシティを適用** は始値と終値を発音時刻に沿って補間します。同時に始まる和音には同じ値が付きます。ノートの中央をドラッグすると移動し、左右端で開始・終了を伸縮します。相対スナップは元のずれを維持し、絶対スナップはつかんだ端をグリッドに揃えます。ドラッグ中の Shift で吸着を一時解除できます。どちらの一括編集も取り消せます。

左パネルの **鉛筆** をオンにすると、空白をクリックしてグリッド幅の音を置けます。右へドラッグすると長さを指定でき、Shift＋ドラッグで範囲選択できます。ピアノロールで **B** を押すと鉛筆を切り替えられます。**Alt／Option＋ドラッグ** でグリッドに沿って連打を入力できます。8分三連のハイハットなら、グリッドを **1/8 T** にして横になぞります。**三連符に分割** は選択した各ノートを元の長さの中で3連打にします。ドラムにも使えます。**ストラムを適用** は選択した同時発音の和音に効きます。低音から、高音から、和音ごとに交互の3方向があり、ストラム幅は四分音符に対する割合です。一度の取り消しで元のタイミングに戻せます。

ドラムを選び、ピアノロールの左上で **スロット・ステップ** に切り替えると、キットのスロット名が縦に並びます。たとえばトラップのハイハットは、1/16 グリッドでハットの行を選び、**1つおきに入力** で8分の刻みを置けます。空いているマスを **ステップ内連打 3** でクリックすると、その16分音符の中に3打が入ります。Shift＋クリックはアクセントです。**カーソルの小節** と1・2・4小節の長さで範囲を決め、**ループ** をオンにして再生してください。ループ再生中に入力した変更は次の周回に反映されます。**ドラム・ノート** に戻すと同じ発音を細かく移動できます。

トラック選択欄の隣の **ベロシティ** メニューから CC、ピッチベンド、チャンネル・アフタータッチ、パン・オートメーションに切り替えられます。下のレーンでクリックして点を置き、ドラッグで時刻と値を調整し、右クリックで消去します。Copper Mile の33小節目からはリードのベンドとパン移動を、41小節目からは2/2・104 BPMのブレイクを確認できます。現在、拍子変更には変更前後の小節長が等しく、小節の先頭で切り替わる曲を読み込めます。

**設定 → 配色テーマ** で、青系の濃淡で表示する **スタジオブルー**（初期設定）と、度数ごとに色相を変える **ハーモニーカラー（多色）** を切り替えられます。設定は次回起動時にも引き継がれます。

トラックの音量・パン・ミュート・ソロ、バスやリターンへの送りはミキサーと連動します。**FX** では最大8個のステレオ VST3 エフェクトを追加し、ドラッグまたは上下ボタンで処理順を変更できます。バス、リターン、マスターにも個別のフェーダー、ミュート、エフェクトがあります。

alpha 3 では、各トラックの横メーターとミキサーの縦メーターで、エフェクト・パン・フェーダーを通った左右のピークを確認できます。バス、リターン、マスターの合成音と、出力3・4に送るキューも個別に表示します。0 dBFS に達すると赤いランプが約1秒点灯します。複数の MIDI トラックでひとつの音源を共有する場合は、その音源を挿したトラックに合成後のレベルが表示されます。

アレンジ下端の **高さ** で対象を選び、隣のスライダーを動かすと、選んだ種類のトラックが同じ高さになります。全体、グローバル、アレンジ、出力のほか、ドラムだけ、バスだけなども選べます。行の高さが異なる場合は「混在」と表示します。アレンジとピアノロールは同じ **ズーム** と横スクロールを使います。上下の境界をドラッグすると表示の高さを配分できます。ピアノ鍵盤の左隣にある縦のつまみを左右にドラッグすると、トラック名欄とピアノロール左パネルの幅が一緒に変わります。右へ動かすと拡大し、ダブルクリックで曲全体に戻ります。隣のスクロールバーで表示位置を移動できます。トラックの下端を上下にドラッグすると、その行の高さが変わります。ダブルクリックで折りたたみ、もう一度ダブルクリックすると元の高さに戻ります。広げた行では音量とパンを操作でき、ノート入りクリップには音程と長さが表示されます。下のトラックへは縦スクロールで移動できます。

## OSTF と OSTFP の保存

**Save as OSTF** はスコアと Studio のミキサー設定を保存します。リンクした WAV は隣の `<曲名>.media` にコピーし、相対パスで参照します。曲を移動するときはこのフォルダーも一緒に移動してください。**Save as OSTFP** はスコア、Production Session の設定、WAV を1ファイルにまとめます。[公式仕様](https://github.com/yoh-nak/Open-Song-Timeline-Format-5.0/tree/d8ce48ca6c873a5a24a94bcc80d847bf33135b46)

alpha 3 の Windows Setup は、共有 VST3 の項目を選ぶと管理者の許可を受け、音源2種とエフェクト9種を `%CommonProgramFiles%\VST3\OSTF Studio` に配置します。他の DAW では VST3 のシステムフォルダーを有効にして再スキャンしてください。同じバージョンで内容も一致する VST3 バイナリは使用中でもそのまま使い、不足ファイルを補います。使用中のプラグインに更新が必要なときは、本体だけ先にインストールできます。後で DAW の作業を保存して閉じ、Setup を再実行して共有 VST3 を選んでください。旧版のプラグインは共有 VST3 のインストール成功後に `%LOCALAPPDATA%\OSTF Studio\Previous VST3` に退避します。共有プラグインは Windows のアプリ一覧から個別にアンインストールできます。Mac では DMG 内の PKG を実行すると `/Library/Audio/Plug-Ins/VST3` に入ります。

## 開発を再開する

リポジトリをクローンし、[開発ルール](AGENTS.md)、[引き継ぎ](HANDOFF.md)、[設計とロードマップ](docs/ARCHITECTURE.md) を読みます。C++20、CMake 3.22 以降、Git が必要です。Windows では Visual Studio 2022 と Windows SDK、macOS では Xcode Command Line Tools を使用します。

```sh
git clone https://github.com/yoh-nak/OSTF-Studio.git
cd OSTF-Studio
cmake -S . -B build-core -DOSTF_STUDIO_BUILD_GUI=OFF
cmake --build build-core --config Release
ctest --test-dir build-core -C Release --output-on-failure --no-tests=error
```

GUI をビルドするには `build-core` を `build` に、`OSTF_STUDIO_BUILD_GUI=OFF` を `ON` に変更します。GUI の構成時に JUCE 9.0.5 を取得します。配布版と同じ GM 音源を使用する場合は先に `python packaging/prepare_fluid_r3.py` を実行してください。Windows x64 と macOS arm64 の CI がビルドと自動テストを行います。実機のオーディオ、外部プラグインとの連携は別途検証します。[ビルドと配布の手順](docs/RELEASING.md)
